# 文学意象书墙 · Desk Archive

50 本书的 3D 书堆展示页（Vite + React + three.js 构建的静态站点），白底黑白线条风。
本文件夹为构建产物（dist），**自包含**：所有 JS/CSS/封面图均为相对路径，放入任何子目录即可运行。

## 快速预览

直接双击 `index.html` 用浏览器打开，或任意静态服务器指向本目录。

## 合并到其他网页

**方式一：iframe 嵌入（推荐，最简单）**

```html
<iframe src="书墙文件夹/index.html" style="width:100%;height:100vh;border:0" title="文学意象"></iframe>
```

可用 URL 参数：
- `?start=24` — 打开时定位到第 25 本（0 起）
- `?book=A-016` — 直接打开某本书的详情弹窗（编号见封面映射表）

**方式二：整体作为子目录**

把整个文件夹拷进主站目录（如 `/desks/`），链接到 `/desks/index.html` 即可。

## 目录结构

```
index.html      入口页
assets/         JS/CSS（哈希命名，可整体替换更新）
covers/         50 张书籍封面图（A-001 ~ A-050）
```

## 说明

- 鼠标滚轮 / 触控板上下滚动切换书籍；点击书本弹出详情；Esc 关闭弹窗
- 书脊文字为程序生成的线稿贴图；封面图版权归原出版社所有，仅作学习展示
